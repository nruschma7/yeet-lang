# yeet-lang

**A programming language where the syntax is as questionable as the decisions made while writing it.**

yeet-lang is a small, experimental programming language written in Haskell, with custom syntax inspired by Gen-Z slang and internet culture. It is a personal fun project for learning about programming language design and implementation.

## Current Features

- Lexer for identifiers, integers, strings, and basic punctuation
- `cook` and `void` keywords
- Error messages for unexpected characters, including line and column
- HTF tests

## Build and Run

```sh
stack build
stack run
stack test
```

## The Goal

Learn something new, experiment with language design, and create something programming along the way. Maybe it'll turn into a usable little language. Maybe it'll become an absolute mess.

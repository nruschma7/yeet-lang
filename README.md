# yeet-lang

**A programming language where the syntax is as questionable as the decisions
made while writing it.**

yeet-lang is a small, experimental programming language written in Haskell,
featuring a custom syntax inspired by Gen-Z slang and internet culture.

This is a personal fun project built for learning about programming language
design, interpreters, parsers, and type systems. No big ambitions, no
revolutionary ideas — just curiosity, questionable keywords, and a lot of experimenting.

## Example

```yeet
cook greet = fn(name) =>
    "yo, " + name + "!";

yap(greet("world"));
```

## Planned Features

- Functional programming
- Immutable bindings
- First-class functions
- Static typing
- Pattern matching
- Algebraic data types
- Custom slang-inspired syntax

Some keywords currently being explored:

| Keyword | Purpose |
| --- | --- |
| `cook` | Define a binding |
| `yap` | Print output |
| `yeet` | Return a value |
| `lowkey` / `highkey` | Conditional expressions |
| `fuck around` / `find out` | Experimental error handling |

Syntax and semantics are still a work in progress.

## The Goal

Learn something new, experiment with language design, and create something programming
along the way.

Maybe it'll turn into a usable little language. Maybe it'll become an absolute mess.
